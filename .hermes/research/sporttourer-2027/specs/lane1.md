## TL;DR — Refined candidate set

The orchestrator's seed set was directionally right but needed three corrections and three additions:

**DROPPED (not on sale in CH for MY2027):**
- Kawasaki ZZR1400 / ZX-14 (Ninja ZX-14R) — production ended 2022 (see F-30).
- Ducati Hyperstrada — discontinued ~2015–2023, not a current model (see F-28).
- Yamaha FJ-09 — discontinued ~2015–2017, not in the current Yamaha touring lineup (see F-29).

**ADDED (real MY2027 sport-tourers the seed set missed):**
- BMW M 1000 RS — brand-new MY2027 sport-tourer (sport-touring M 1000 RR), EPA/CARB-certified (see F-09).
- Honda CB 1000 GT — brand-new MY2026 sport-tourer (Fireblade/Hornet DNA), on sale from Feb 2026 (see F-15).
- Kawasaki Ninja 1100SX — brand-new MY2026 model that REPLACES the Ninja 1000 as Kawasaki's sport-tourer (see F-11).
- Yamaha Tracer 9 — the top-tier Yamaha sport-tourer (890cc CP3); the seed set only listed the mid-size Tracer 7 (see F-17).

**CATEGORIZED (seed set mixed true sport-tourers with other categories):**
- True sport-tourers (core of the purchase comparison): BMW S 1000 XR, M 1000 XR, R 1300 RS, F 900 XR, M 1000 RS (new); Kawasaki Ninja 1100SX; Honda CB 1000 GT; Yamaha Tracer 9 / Tracer 7; Ducati Multistrada V4.
- Naked sport bikes (fast, but not touring-oriented): KTM 1290 Super Duke R, Aprilia Tuono V4, Triumph Speed Triple 1200 RS, Suzuki GSX-S1000 / GSX-S1000GX+.
- Superbikes / hyper-sport (track/outright-speed, not sport-tourers): Honda CBR1000RR-R Fireblade SP (the "CBR1100XX" in the seed set is the pre-2020 name), Suzuki Hayabusa.
- Light-adventure / mid: Triumph Tiger Sport 800 (light adventure), Honda CBR650R (mid supersport).

The final German report should rank the TRUE sport-tourers first; the naked/superbike entries are kept for completeness because the orchestrator seeded them, but they are flagged as a different category.
